# cinema-dna-21x9x3

Codex skill for turning people, spaces, products, architecture, reference images, or story ideas into cinematic 21:9 film-still prompts, with a default three-shot triptych rhythm.

## Contents

- `SKILL.md` - main skill instructions
- `references/` - extended cinema grammar and anti-AI film-frame patches
- `agents/` - display metadata

## Install

Copy this folder into your Codex skills directory, for example:

```powershell
Copy-Item -Recurse . "$env:USERPROFILE\.codex\skills\cinema-dna-21x9x3"
```
